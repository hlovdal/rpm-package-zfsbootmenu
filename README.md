# Summary

[ZFSBootMenu](https://github.com/zbm-dev/zfsbootmenu) is a Linux
bootloader that knows how to find Linux kernels within ZFS filesystems
and boot from those.

This repo is creating
[rpm packages](https://copr.fedorainfracloud.org/coprs/hlovdal/rpm-package-zfsbootmenu/)
for this.

Notice that if you install ZFSBootMenu via EFI you probably do not need
this package. It is only strictly needed if you boot via BIOS.

This repository is primarily created for my own personal use, but if it
is useful for others, good on them.
